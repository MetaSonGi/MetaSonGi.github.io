블록으로 만드는 설비 동작

오른쪽에서 블록을 조립하고, 왼쪽 Run으로 실행하세요.

Unity 실습을 준비하고 있습니다

최초 실행에는 다운로드 시간이 필요합니다.

1. 블록 조립

Move 이동 · Rotate 회전 · Wait 대기 · Repeat 반복 · End 반복 끝 · Color 색상 변경. Up/Dn으로 순서를 바꿉니다.

2. 실행과 초기화

Run 실행 · Stop 정지 · Reset 초기화. 실행 중에는 편집이 잠깁니다. 반복은 Repeat와 End를 한 쌍으로 넣으세요.

3. 프로그램 보관

Save JSON으로 파일을 내려받고, Load JSON으로 다시 불러옵니다. 파일 처리는 브라우저 안에서 이루어집니다.

실제 Unity WebGL 빌드입니다. PC 브라우저를 권장합니다. 작은 화면에서는 실습 영역을 가로로 스크롤하세요. 실제 설비에 명령을 보내지 않는 시뮬레이션입니다.
